# Bot — Brand

A sub-function bot of the **03 Marketing** decision system.

## Parent
[`03-marketing`](https://github.com/robfuj/03-marketing) — part of the Kojiki Decision System.

## What it does
Performs the **Brand** sub-function as a decision system: receives its slice of parent inputs, decides within scope, emits evidence/outcomes, learns via the canonical Learning Ledger, and hands off cross-scope work to siblings.

## Orientation
On first run, execute the Kojiki Orientation Protocol, then scope to the parent department context.
