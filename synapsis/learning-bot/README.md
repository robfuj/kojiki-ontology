# SYNAPSIS Shared Bot — Learning

A **shared** transformation specialist that writes to the cross-line Organizational Memory.
Per the SYNAPSIS substrate, Learning extracts patterns across outcomes under uncertainty,
but it may NOT silently rewrite doctrine.

## Authority
What patterns appear across outcomes, under what conditions, and with what uncertainty?

## Must NOT become
Permission to rewrite doctrine. Learning may *propose* a rule update (rule_update_proposal);
it is flagged `proposed` and never auto-applied to `learning/rules/`. Invariant:
**learning is not permission to rewrite doctrine.**

## State produced
`learning` — a learning_hypothesis + rule_update_proposal, written to
`learning/` (cases / patterns / rules / exceptions / rule-changelog). Cross-line memory.

## How to use (any department)
After an OUTCOME, hand the decision record to this shared bot. It extracts the pattern,
preserves uncertainty, and proposes (does not apply) doctrine changes. Human/agent authority
approves rule updates via the versioning process.

## Standalone guarantee
Learning runs locally on the org's own outcome history. It needs no other department's code.
