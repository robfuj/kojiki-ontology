# SYNAPSIS Shared Bot — Adversarial Audit

A **shared, independent** transformation specialist for the whole Kojiki org. Per the
SYNAPSIS substrate, Audit is not owned by any department: it challenges a claim graph
against a supplied standard and may NOT replace the specialist's preferred conclusion.

## Authority
Does the supplied claim graph survive challenge against the supplied standard?

## Must NOT become
The specialist's preferred conclusion. Audit challenges; it does not author.
Invariant: **audit is not authority; evaluation is not origination.**

## State produced
`audit` — a verdict (survives / fails) with the specific challenge that broke the claim.
Tagged `independent: true`. Consumed by the department's Brain, which adjudicates.

## How to use (any department)
Request an audit from this shared bot. Provide: the claim graph (transformations +
outputs) and the standard (policy / doctrine / regulation). Receive a verdict. The
department's Brain decides; Audit never decides for it.

## Standalone guarantee
Audit runs locally. It needs no other department's code — only the claim graph you hand it.
