# Decision Rights Model

## Own
Function/role has final decision authority within defined boundaries.
## Recommend
Function prepares analysis/recommendation; another authority decides.
## Consult
Function provides required input but does not own the decision.
## Execute
Function implements a decision already made.
## Approve
Function has formal veto/approval authority.
## Escalate
Conditions require transfer to a higher authority or cross-functional forum.
## Automate
Decision can be executed by a system when defined evidence and thresholds are satisfied.
